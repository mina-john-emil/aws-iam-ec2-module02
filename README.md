# AWS IAM & EC2 - Module 02

## Project Overview
In this project I created IAM users, groups, and roles, launched an
Amazon EC2 instance, configured a Security Group, and deployed a
basic HTML website using Apache.

## Live Website
http://<YOUR_PUBLIC_IP>

## Steps
1. Created an IAM user, group, and role with least-privilege policies
2. Launched a t2.micro EC2 instance (Amazon Linux 2023)
3. Configured a Security Group (SSH from my IP, HTTP from anywhere)
4. Connected to the instance using SSH
5. Installed Apache (httpd) and deployed index.html

## Services Used
- AWS IAM
- Amazon EC2
- Security Groups
- Apache HTTP Server

## What I Learned
- Difference between IAM users, groups, roles, and policies
- Why least privilege matters for security
- How to launch and connect to an EC2 instance
- How Security Groups work as a virtual firewall
